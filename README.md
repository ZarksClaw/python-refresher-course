# Python Refresher Course

Interactive Q&A refresher course for Python developers. 11 chapters covering Python fundamentals through advanced topics. No build tools or dependencies — just open `index.html` in a browser.

## Course Content

| # | Chapter |
|---|---------|
| 1 | Python Basics |
| 2 | Control Flow |
| 3 | Functions & Scope |
| 4 | Data Structures |
| 5 | String Manipulation |
| 6 | File I/O |
| 7 | Error Handling & Exceptions |
| 8 | Modules & Packages |
| 9 | Object-Oriented Programming |
| 10 | Advanced Topics |
| 11 | Standard Library Highlights |

## How to Use

Open `index.html` in any browser, or serve locally:

```bash
python3 -m http.server 8080
```
